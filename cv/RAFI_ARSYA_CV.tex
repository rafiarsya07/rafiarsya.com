\section*{Selected Projects}

\project{PaperMind: Local RAG Paper Analyzer}{2026}{Ask questions of any PDF and get grounded
answers from a local LLM. FastAPI backend, ChromaDB vector store, Ollama (phi3:mini) inference.
Fully offline with zero external API calls, containerised with Docker Compose and self-hosted on
a Linux mini PC behind a Cloudflare Tunnel.}

\project{AI Digit Recognizer: CNN Built From Scratch}{2026}{Convolutional network written
entirely in NumPy: im2col-vectorized convolutions, max-pooling, backpropagation and Adam, with no
PyTorch and no TensorFlow. 99.1\% test accuracy on MNIST, served by Flask with a visualizer
rendering per-pixel saliency and live signal flow through every layer.}

\project{ThoughtLog: Full-Stack Blog with Custom CMS}{2026}{Node.js, Express and PostgreSQL with
Markdown authoring and a three-state auto-publishing scheduler. Full-text search on tsvector/GIN
with tag filtering, RSS and email subscriptions. Self-hosted behind a Cloudflare Tunnel,
PM2-managed, deployed via GitHub Actions.}

\project{Steam Market Intelligence}{2026}{In-browser analytics over a 1,400-title dataset running
real SQLite compiled to WebAssembly, with a live query console. Window functions and recursive
CTEs execute client-side, so there is no backend and no precomputed export.}

\project{snip: Serverless URL Shortener}{2026}{API Gateway, Lambda and DynamoDB defined as
infrastructure-as-code with AWS SAM for one-command provisioning. No managed server,
least-privilege IAM per function, scales to zero when idle.}

\project{Crop Disease Detector}{2026}{Leaf-photo classifier across 38 disease categories trained
on PlantVillage (54K+ images). MobileNetV2 transfer learning with data augmentation and two-phase
fine-tuning in TensorFlow/Keras, deployed to Hugging Face Spaces with top-3 confidence scores.}

\project{IDFEST 2026 Website}{2026}{Official site for an international cultural event at
Universiti Malaya, built with a committee. Next.js 16 static export, React 19 and Tailwind CSS v4.
Owned the homepage timeline, hero responsiveness across breakpoints, and the shared navigation and
mascot components reused across sections.}

\project{Arena Duel}{2026}{Server-authoritative real-time 1v1 over WebSockets. Simultaneous blind
actions resolved deterministically server-side, with state machines, cooldowns and disconnect
handling, so the client is never trusted with the outcome.}
